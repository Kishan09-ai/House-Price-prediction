# 🏠 House Price Prediction

A Machine Learning-based **House Price Prediction web application** that predicts the estimated price of a house based on user-provided property features.

The project combines a **Machine Learning model with a simple and responsive web interface**, allowing users to enter property details and get a predicted house price.

## 📌 Project Overview

The Machine Learning model is trained using regression techniques to learn the relationship between different house features and their prices.

The project also includes a frontend developed using **HTML and CSS**, providing a clean interface for users to enter their property information and view the prediction.

## 🌐 Web Interface

The frontend allows users to:

* Enter house/property details
* Submit the information
* Get the predicted house price
* Interact with the prediction system through a simple user-friendly interface

The interface is designed using **HTML and CSS**.

## 📊 Project Workflow

1. Collect and load the housing dataset
2. Perform data preprocessing
3. Explore and visualize the dataset
4. Train the regression model
5. Generate predictions
6. Build the frontend using HTML and CSS
7. Connect the prediction model with the web interface
8. Display the predicted house price to the user

## 🎯 Objective

The main objective of this project is to understand how **Machine Learning models can be integrated into a web application** to solve a real-world problem such as house price prediction.
